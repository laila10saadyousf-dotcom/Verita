# 📎 Project Name: Verita

 # 📌 Project Overview: 
 A smart platform that helps users verify the reliability of sellers and products before making a purchase decision. Stores can apply for the "TrustCart Verified Badge" for a fee, provided they meet specific criteria and conditions that ensure their trustworthiness.

  # 🎯 Project Objectives : 
  Verita aims to reduce the trust gap between online buyers and sellers by helping users evaluate the reliability of a seller, product, and offer before making a purchase. It provides a clear Trust Score, risk indicators, and simple explanations to support safer and more informed purchasing decisions, while helping trustworthy businesses prove their credibility.

  # 📦 Project Scope :
 ## The first version of Verita focuses on the pre-purchase experience.
  ### **For Buyers:** 
- Enter a product or store link.
- View a Trust Score.
- Understand risk factors and reasons behind the score.
- Receive recommendations before purchasing.
- Compare more trustworthy alternatives.
### **For Sellers:** 
- Create a verified business profile.
- Display business, payment, and return information.
- Receive a Trust Score.
- Identify weaknesses affecting customer trust.
- Get recommendations to improve credibility.

 The system analyzes seller information, product details, pricing, reviews, payment methods, and return/refund policies, then converts them into a Trust Score, risk indicators, and clear recommendations.
